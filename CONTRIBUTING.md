# Contributing to ALG Vector Engine

Thank you for your interest in contributing.

## Contribution Requirements

By submitting a contribution, you certify that:

1. You created the contribution, or have the legal right to submit it.
2. The contribution does not knowingly violate third-party intellectual property rights.
3. You agree that your contribution will be distributed under the Apache License, Version 2.0.
4. Any third-party code, dependencies, algorithms or externally sourced materials must be explicitly identified.

## Developer Certificate of Origin

All commits submitted through pull requests must include a Signed-off-by line certifying compliance with the Developer Certificate of Origin (DCO).

Example:

```
Signed-off-by: Developer Name <developer@example.com>
```

You can automatically add this line to your commits using:

```bash
git commit -s -m "commit message"
```

## Code Review

All contributions require maintainer approval before merging.
The project maintainer retains authority over release management, versioning and public SDK distributions.
